
# BSNL Bulk Invoice Editor

A Streamlit application for bulk editing BSNL
Leased Circuit PDF invoices.

## Features

- Multiple PDF uploads
- Reads Total Current Charges
- Updates five amount fields
- Previous Balance set to zero
- Last Payment set to zero
- Amount in Words conversion
- ZIP download of revised invoices

## Installation

pip install -r requirements.txt

## Run

streamlit run app.py

## Deployment

Deploy through Streamlit Community Cloud
using GitHub.

## Important

Designed for the supplied BSNL invoice template.
Verify all revised invoices before official use.
